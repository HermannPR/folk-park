# ADR-0001: Pin JUCE 8.0.13 as a Git submodule

- Status: Accepted for private engineering; license remains a distribution gate.
- Date: 2026-08-20

## Context

Folk Park requires VST3/Standalone targets, macOS WebKit integration, bundled WebView resources, host state/automation, and cross-platform DSP primitives. A moving JUCE branch would make build and compatibility evidence non-reproducible.

## Decision

Use official JUCE tag 8.0.13 at immutable commit `7c9d3783b127263d72bb65fe0a7e2dc8a02a7ac2` as `third_party/JUCE`. Bootstrap fails if the checkout differs. CMake is the source of truth; Projucer is not used.

## Consequences

Clones require `git submodule update --init --recursive`. WebView helper JavaScript is embedded from the same pin, eliminating runtime CDN/server dependencies. JUCE upgrade work requires a new ADR, license review, clean Debug/Release builds, native tests, plugin validation, and host regression status. No binary distribution is authorized until Hermann chooses an applicable JUCE license.
