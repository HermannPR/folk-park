# Compatibility and legal boundary

`folk park` is an original product. Release 0.1 does not implement or promise full or partial decoding of Serum private preset state.

Safe 0.1 compatibility is limited to importing user-owned WAV audio into a documented deterministic wavetable conversion pipeline and loading native versioned `.folkparkpreset` data.

Before any Serum-specific importer work:

1. Separate generic FXP container facts from private payload interpretation.
2. Identify a legitimate public specification or obtain explicit permission.
3. Confirm the owner has rights to each test fixture and asset.
4. Publish a parameter-by-parameter supported subset and unsupported mappings.
5. Require automated state/audio parity evidence before stronger compatibility wording.

Never ship Serum factory assets, preset names, artwork, extracted code, or copied interface design. VST3 SDK licensing does not grant Serum format or asset rights.
